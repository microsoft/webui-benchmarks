# Support

For benchmark bugs, methodology questions, and documentation issues, search
the [existing issues](https://github.com/microsoft/webui-benchmarks/issues)
and open an issue in this repository if needed. See
[Contributing](./CONTRIBUTING.md) for what to include.

For issues with the WebUI framework itself rather than this benchmark suite,
see the [WebUI repository](https://github.com/microsoft/webui).

Please open or join an issue instead of submitting a pull request. Maintainers
will ask for a pull request in the issue if help is needed; see
[Contributing](./CONTRIBUTING.md).

Do not report security vulnerabilities in public issues. Follow
[SECURITY.md](./SECURITY.md) instead.

## Microsoft Support Policy

Support for this project is limited to the resources listed above.
